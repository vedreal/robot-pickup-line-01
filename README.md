One pickup line, a single line of at most 200 characters, in the voice of a robot trying to charm someone — written for make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC. The entry is chosen from ten fresh candidates, each scored against the judge's published brief in its own order: a robot's pickup line first, then a joke that grows out of being a machine, then surprise, economy, and charm.

## Run it

```sh
python3 main.py
```

Writes the winning line to `/output/entry.txt` (1–200 characters, single line).
